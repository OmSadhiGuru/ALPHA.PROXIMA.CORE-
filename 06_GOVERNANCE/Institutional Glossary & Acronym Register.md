## Cross-cutting Glossary

*Terms that recur across the whole institution. Domain-specific terms live in their program glossaries.*

| Term | Definition |
|------|-----------|
| **Alpha Proxima** | The constitutional institution / Foundation; identity is permanent, independent of any reasoning engine. |
| **Cognitive Function** | A permanent institutional capability (Tier I); constitutional. Distinct from the reasoning engine that fulfills it. |
| **Reasoning Engine** | The provisional AI model/system currently fulfilling a cognitive function (Tier II); appointed and replaceable. |
| **Engine Abstraction Principle** | Cognitive functions endure; reasoning engines are appointed and replaceable (Book IV). |
| **Cognitive Council** | Operational governance body for the cognitive-function portfolio (Book V). |
| **AI Ratification Council** | Ratifies engine appointments and AI-architecture changes (formerly "AI Council"). |
| **Alpha Council** | Supreme deliberative/executive body (Book I); human seats currently unfilled. |
| **Interim Authority** | Founder exercising Alpha Council authority until seats are filled (Interim Authority Instrument). |
| **Framework Charter** | A constitution governing a framework/product (LUMIAION, Genome), subordinate to Book I (rank 4). |
| **Evidence class** | Six-class system: C consensus · M competing models · E emerging · Q open question · S speculative · P phenomenological (Book III). |
| **Architectural Blocker vs Documentation Debt** | Only blockers stop progress; debt is tracked and scheduled ([[Research Debt Register]]). |
| **Epoch** | A major phase of institutional development (I–V; see [[Institutional Timeline]]). |
| **Transformation Path** *(OSG)* | Knowledge → Reflection → Practice → Integration → Application → Growth (OLS). |
| **Living Genome** | An evolving information architecture of a person's knowledge/development (Genome Constitution). |
